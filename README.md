# plp-python-week4
# Week 4 Assignment: Hands-On Lab - Grades, Eligibility & Smart Decisions

## Description
- `welcome.py`: Defines a function `welcome(name)` that returns a formatted greeting string for a given name.
- `toolbox.py`: Contains utility functions (`double`, `is_pass`, and `greet`) to handle basic math, score validation, and custom greeting logic.

## Reflection
The `greet` function was the most challenging to write because it required handling a default parameter value while correctly formatting string output with punctuation.
